How a document flows through the pipeline
Every path ends in validated JSON or an explicit flag; nothing bad is passed on silently
Load
PDF / image. Corrupt, empty, password-protected or unsupported files return a typed error.
Route
Text layer → text model (exact chars). Scans → auto-upright, 200 dpi, vision model.
Extract
LLM in JSON mode with the sample-pack labelling rules in the prompt.
Validate
Pydantic schema, required fields, Σ items + tax = total, qty × price, due-date sanity.
Retry
Up to 2 corrective turns quoting the exact validation errors; best attempt kept.
Flag
Anything still failing → needs_review with reasons.

Matching rules
eval/metrics.py

          
is_invoice       exact boolean
vendor           case/punctuation-insensitive, legal suffixes canonicalised (Pvt Ltd = Private Limited, Ltd = Limited, Co = Company)
                 equal canonical names, or fuzz.ratio >= 90. No subset matching ("Acme" != "Acme Holdings Global")
invoice_number   exact after trimming whitespace and upper-casing
invoice_date     exact ISO YYYY-MM-DD
currency         exact ISO-4217 code (case-insensitive)
tax_total/total  |pred - gt| <= 0.01 after parsing ("1,200.00" == 1200)
line_items       strict: same row count, in order; description fuzz >= 80, quantity equal or both null, amount within 0.01
                 (row-level precision/recall reported separately)
both null        counts as a match (non-invoices)
